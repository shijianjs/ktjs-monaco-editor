<ktjs-features section-title="What the wrapper gives you" tinted>

<ktjs-feature icon="lucide:type" title="Types, not dynamic">Every declaration in monaco's `editor.api.d.ts` becomes an `external` Kotlin declaration: options are checked when you build an object literal, and a misspelled member fails the build.</ktjs-feature>

<ktjs-feature icon="lucide:code" title="The same API as TypeScript">`Monaco.editor` and `Monaco.languages` are the package's own namespace objects; `Monaco.Range`, `Monaco.Uri` and `Monaco.KeyMod` are the exported value classes, with factories for construction.</ktjs-feature>

<ktjs-feature icon="lucide:refresh-cw" title="Generated from upstream">`scripts/generate-api.py` reads the declaration file and writes the wrapper, so an npm upgrade is a regeneration instead of a rewrite — 300 interfaces, 17 classes, 48 enums.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested in a real browser">The module's cases run in Chromium through Karma against the real package; the demo's Playwright suite checks the production bundle, CSS and workers included.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs are Kotlin too">This site is a Kotlin/JS module built by ktjs-docusaurus: typed configuration and sidebars, Markdown pages, English and Chinese.</ktjs-feature>

<ktjs-feature icon="lucide:rocket" title="Pages wired">`pagesSite` assembles this documentation, the demo under `/demo/` and the Dokka reference under `/api/`; the Pages workflow deploys them together.</ktjs-feature>

</ktjs-features>
