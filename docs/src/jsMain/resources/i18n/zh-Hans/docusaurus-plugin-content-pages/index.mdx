<ktjs-features section-title="封装带来了什么" tinted>

<ktjs-feature icon="lucide:type" title="类型而不是 dynamic">monaco `editor.api.d.ts` 里的每条声明都变成 Kotlin `external` 声明：构造对象字面量时选项受检查，成员拼错就构建失败。</ktjs-feature>

<ktjs-feature icon="lucide:code" title="与 TypeScript 同一套 API">`Monaco.editor`、`Monaco.languages` 就是包自己的命名空间对象；`Monaco.Range`、`Monaco.Uri`、`Monaco.KeyMod` 是导出的值类，并配了用于构造的工厂。</ktjs-feature>

<ktjs-feature icon="lucide:refresh-cw" title="由上游生成">`scripts/generate-api.py` 读声明文件并写出封装，所以升级 npm 版本等于重新生成而不是重写——300 个 interface、17 个 class、48 个 enum。</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="在真实浏览器里测">模块的用例通过 Karma 在 Chromium 里跑真实包；demo 的 Playwright 套件检查生产 bundle，包括 CSS 与 worker。</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="文档也是 Kotlin">本站就是由 ktjs-docusaurus 构建的 Kotlin/JS 模块：类型化的配置与侧边栏、Markdown 页面、中英双语。</ktjs-feature>

<ktjs-feature icon="lucide:rocket" title="Pages 已接好">`pagesSite` 组装本站、`/demo/` 下的演示和 `/api/` 下的 Dokka 文档，Pages 工作流一次部署三份产物。</ktjs-feature>

</ktjs-features>
